# VTA-Helper-SourceEngine
VTA_FLEX_TOOL and VTA_BATCH_FLEX_TOOL — tools for working with flexes (shape keys) in VTA files

VTA_FLEX_TOOL and VTA_BATCH_FLEX_TOOL are a set of utilities designed for convenient processing and modification of flexes (shape keys) in VTA files used in Source Engine models. These applications simplify facial animation deformation editing and allow users to quickly scale or adjust flex values without manually editing the file structure.
